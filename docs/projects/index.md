## Running and interpreting the examples

Run commands from the repository root after preparing the project dependencies described in the README. On Windows, use `py -3.14` in place of `python` if that is your installed launcher. The **Complete source** section of each project contains the maintained script.

P1 and P5–P8 use small offline CPU defaults. P2–P4 offer `--smoke-test` without dataset downloads; their training runs use `--device auto` and may download missing public datasets. Add `--device cpu` to require CPU. Optional full/GPU runs increase the budget and need compatible hardware.

P1 refreshes a checked-in prediction image. Run it in a disposable copy when you want to preserve the retained chart. Other experiment outputs belong under ignored `artifacts/`; a weight file needs its architecture and input contract to be useful later.

!!! note "What a small run proves"
    Synthetic inputs and smoke checks make mechanics inspectable. They do not establish real-data quality, pretrained transfer performance or a device speedup. Compare a reported value with its declared inputs, configuration and evidence before drawing a conclusion.
